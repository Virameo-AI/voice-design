API

Always on

This dashboard runs on it. Scripts and agents can call it directly when MCP is unavailable.

curl -X POST http://127.0.0.1:8180/v1/renders \
  -H "Authorization: Bearer $VOICE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"voice_id":"narrator-warm-v1","style":"narration",
       "text":"[calm] The room went quiet."}'

curl -H "Authorization: Bearer $VOICE_TOKEN" \
  -o narration.wav \
  http://127.0.0.1:8180/v1/jobs/JOB_ID/files/audio.wav
